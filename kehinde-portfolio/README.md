# Kehinde Developer Portfolio

A responsive, premium dark-theme developer portfolio made with HTML, CSS and vanilla JavaScript.

## Open locally
1. Open this folder in VS Code.
2. Install the **Live Server** extension, if needed.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Alternatively, open `index.html` directly in a browser.

## Files
- `index.html` — page content and layout
- `styles.css` — responsive design and theme
- `script.js` — mobile navigation, reveal effects, copyright year
- `assets/Kehinde_CV.pdf` — downloadable CV (add your latest CV here if missing)

## Before publishing
- Verify your GitHub username and repository URL.
- Check your project details and professional dates.
- Confirm that `assets/Kehinde_CV.pdf` is present and current.
- Replace the illustrative FundHaven project mockup with an actual screenshot when ready.

## Deploy
Upload this folder to a new GitHub repository, then import the repository into Vercel or Netlify as a static website. No build command is required.
